# YF ERP 系统发布版本

元风跟单王 ERP 系统的官方发布版本。

## 下载

请在 [Releases](https://github.com/Harwav/YF_ERP_Releases/releases) 页面下载最新版本。

### 最新版本

| 文件 | 说明 |
|------|------|
| `ERP_Server_Tray_vX.X.X.X.exe` | ERP 主程序 |

## 安装说明

1. 下载 `ERP_Server_Tray_vX.X.X.X.exe`
2. 双击运行程序
3. 首次运行会自动创建数据库和配置文件
4. 程序启动后会在系统托盘显示图标
5. 浏览器访问 `http://localhost:8080` 使用系统

## 系统要求

- Windows 10 或 Windows 11
- 至少 4GB 内存
- 500MB 可用磁盘空间

# YF ERP System Releases

Official releases for YF ERP System.

## Download

Download the latest version from the [Releases](https://github.com/Harwav/YF_ERP_Releases/releases) page.

## Installation

1. Download `ERP_Server_Tray_vX.X.X.X.exe`
2. Double-click to run
3. First run will automatically create database and config files
4. Program icon appears in system tray
5. Access the system at `http://localhost:8080`

## System Requirements

- Windows 10 or Windows 11
- At least 4GB RAM
- 500MB free disk space
